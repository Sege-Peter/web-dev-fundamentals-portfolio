Margin creates space outside an element's border, pushing neighboring elements away. Padding creates space inside an element's border, between the border and the inner content.
In standard `content-box`, adding padding or border expands the total rendered size beyond the specified `width`. With `border-box`, padding and borders are absorbed into the declared width, making responsive grid calculations predictable.
`var` is function-scoped and hoisted. `let` and `const` are block-scoped. `const` prevents reassignment of the variable identifier, making code less prone to accidental side-effects. Always default to `const`, and use `let` only when reassigning.
Git is an open-source, local version control command-line tool installed on your computer. GitHub is a cloud hosting platform for Git repositories with collaborative features like pull requests, issue tracking, and automated CI/CD workflows.
