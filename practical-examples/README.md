# 🧪 Web Development Practical Labs & Copyable Examples

This directory contains production-ready, standalone, copyable components and mini-projects built with pure Semantic HTML5, CSS3, and Vanilla JavaScript.

Learners can copy each folder or file directly into their own projects and homework assignments.

---

## 📂 Practical Labs Overview

| Lab Directory | Component / Project | Key Skills & Features |
| :--- | :--- | :--- |
| [`01-accessible-interactive-modal/`](01-accessible-interactive-modal/) | **Accessible Modal Window** | Focus trapping, Escape key listener, backdrop dismissal, ARIA dialog attributes, body scroll-lock. |
| [`02-responsive-navbar-drawer/`](02-responsive-navbar-drawer/) | **Responsive Navbar Drawer** | Mobile-first CSS, hamburger bar transform animation, off-canvas slide-in, backdrop blur. |
| [`03-faq-accordion-component/`](03-faq-accordion-component/) | **Accessible FAQ Accordion** | Modern CSS Grid 0fr ➔ 1fr height animation, Arrow Up/Down keyboard navigation, event delegation. |
| [`04-dynamic-todo-localstorage/`](04-dynamic-todo-localstorage/) | **Dynamic Task Tracker** | Full CRUD state management, browser `localStorage` persistence, task filters, XSS defense. |
| [`05-async-fetch-quote-generator/`](05-async-fetch-quote-generator/) | **Async Fetch Quote Generator** | `async/await`, HTTP error boundary, fallback offline data, native Clipboard API copy. |

---

## 🚀 How Learners Can Use These Labs

1. **Direct Study & Run**:
   - Navigate into any lab folder (e.g. `practical-examples/01-accessible-interactive-modal/`).
   - Double-click `index.html` to run it in your browser immediately.
2. **Copy to Your Project**:
   - Copy the HTML block inside the `<main>` or body into your project's `index.html`.
   - Copy the CSS rules to your stylesheet.
   - Copy the JavaScript functions into your `app.js`.
3. **Experiment & Modify**:
   - Try changing colors, adding new features (e.g. adding a search bar to the Todo Tracker, or auto-refresh timer to the Quote Generator).
