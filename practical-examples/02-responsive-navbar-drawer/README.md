# Practical Lab 02: Responsive Navbar Drawer

A mobile-first navigation bar featuring a slide-in drawer, animated hamburger-to-close transformation, backdrop overlay, and complete accessibility controls.

---

## 🎯 What Learners Will Master

1. **Mobile-First CSS Media Queries**:
   - Creating a horizontal flexbox navigation for desktop screens (`min-width: 769px`).
   - Converting the navigation into a right-aligned sliding drawer on mobile (`max-width: 768px`).
2. **CSS Transform Animations**:
   - `transform: translateX(100%)` for smooth hardware-accelerated off-screen sliding.
   - 3-line hamburger bar rotation into an 'X' icon without external SVG libraries.
3. **Accessibility**:
   - `aria-expanded="true/false"` tracking drawer state for screen readers.
   - Body scroll-locking on mobile to prevent double scrolling.
